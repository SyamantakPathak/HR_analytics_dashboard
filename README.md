
## HR Analytics Dashboard

###  Overview

The **HR Analytics Dashboard** is an interactive Power BI report designed to analyze and visualize key HR metrics. It provides insights into employee performance, attrition, demographics, and departmental trends to help HR teams make data-driven decisions.

### Key Features

* Employee attrition and retention analysis
* Gender and age distribution
* Department-wise performance metrics
* Job satisfaction and salary insights
* Interactive filters for role, department, and experience

###  Tools & Technologies

* **Power BI Desktop**
* **Data Source:** (e.g., Excel/CSV/SQL database — update as per source)
* **DAX Functions:** Used for measures like attrition rate, average salary, and headcount trends

### Purpose

To help HR professionals and management monitor workforce health, identify improvement areas, and optimize talent management strategies.

### File Information

* **File Name:** `HRanalytics_Dashboard.pbix`
* **Software Required:** Microsoft Power BI Desktop
